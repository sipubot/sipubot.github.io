# sipubot.github.io

정적 웹 포트폴리오 사이트이자, 개인 대시보드와 여러 작은 웹 애플리케이션을 한곳에 모아둔 프로젝트입니다. GitHub Pages에서 운영되는 형태로 구성되어 있으며, 현재는 프로필, 앱 링크, 명언 게시판, 개인 정보/통계 화면을 중심으로 동작합니다.

## 프로젝트 개요

이 프로젝트는 단일 페이지 기반으로 구성된 개인 웹사이트이며, `index.html` 안에서 여러 섹션을 전환하면서 앱 목록과 개인 상태를 보여줍니다. 자바스크립트는 `js/` 디렉터리의 공통 스크립트와 각종 컴포넌트를 통해 동작을 제어합니다.

## 포함된 기능

- 개인 프로필/홈 화면
- 상태(Stat) 카드 표시
- 앱 링크 목록
- 명언/메시지 게시판
- 로그인/로그아웃 모달
- 캔버스 기반 애니메이션 요소
- Google Analytics 연동

## 기술 스택

- HTML5
- CSS3
- JavaScript
- Bootstrap
- jQuery
- Chart.js / Google Charts
- GitHub Pages

## 로컬 실행

브라우저에서 바로 열어볼 수 있습니다.

```bash
cd sipubot.github.io
python -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000`으로 접속합니다.

## 주요 포인트

- 정적 사이트이며 서버 환경이 거의 필요하지 않습니다.
- 각 앱은 별도의 디렉터리로 분리되어 있어 확장이 쉽게 구성되어 있습니다.
- 메인 페이지는 공통 UI와 링크 구성을 통해 여러 작은 프로젝트를 노출하는 포트폴리오 역할을 합니다.

## 운영 고려사항

- GitHub Pages에서 정적 파일만 서빙하므로 백엔드 로직은 포함되어 있지 않습니다.
- 로그인, 데이터 저장, 사용자 관리 기능은 서버 기반 애플리케이션과 결합해서 사용하는 전제입니다.
- 일부 하위 앱이나 스크립트는 별도 프로젝트 또는 외부 데이터 구조를 기대할 수 있습니다.
